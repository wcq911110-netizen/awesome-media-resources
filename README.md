## 🎥 无版权高清视频素材

* [Pexels Video](https://www.pexels.com/zh-cn/video/) - 全球最大的免费高清/4K 视频素材库，无需标注出处即可免费商用。
* [Pixabay Videos](https://pixabay.com/zh/videos/) - 涵盖大量风景、CG、慢动作视频，完全免费商用。
* [Coverr](https://coverr.co/) - 专门提供高质量网页背景视频与航拍镜头，每周更新。
* [Mixkit](https://mixkit.co/) - 包含丰富的视频片段、Pr/AE 视频模板以及过渡动画，全部免费。

## 🎵 免费可商用音乐与音效

* [YouTube Audio Library](https://www.youtube.com/audiolibrary) - YouTube 官方背景音乐与音效库，安全无版权风险（需登录）。
* [Freesound](https://freesound.org/) - 庞大的音效数据库，适合查找各种日常生活、影视特效音。
* [Incompetech](https://incompetech.com/) - 著名音乐人 Kevin MacLeod 的免版权音乐库（注明出处即可免费使用）。
* [Bensound](https://www.bensound.com/) - 提供多种风格的优质背景音乐（部分免费，需注明出处）。

## 💡 避坑提示（版权须知）

1. **知识共享协议（CC0）**：表示创作者放弃版权，可以任意修改、免费商用、无需标明出处。
2. **CC-BY 协议**：可以免费商用，但必须在视频简介或结尾**注明原作者**。
3. **肖像权风险**：虽然图片/视频本身无版权，但如果画面中有清晰的真人面部或品牌 Logo，用于商业广告时需谨慎。
